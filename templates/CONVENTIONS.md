# CONVENTIONS.md

Read the Concoct executable's built-in protocol, `.concoct/policy.md`, and
`AGENTS.md` in that order.

This file exists as a thin adapter for tools that prefer a generic conventions file.

Canonical project instructions live in:

```text
AGENTS.md
```

Active task context lives in:

```text
.concoct/current/task-plan.md
.concoct/current/notes.md
```

Role-specific working guidance is rendered from the Concoct executable. Use the
persona included in the current task prompt after the attributed protocol,
policy, and project-guidance layers.

Use hyphens, not underscores, in file and directory names.
